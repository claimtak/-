## 🚀 GitHub Pages वर Deploy कसे करायचे

1. GitHub वर नवीन repository तयार करा — उदा. `mi-aajpasun-daru-sodli`
2. खालील 4 फाइल्स commit करा:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. **Settings → Pages** वर जा
4. Source: **Deploy from a branch** → Branch: **main** → Folder: **/ (root)**
5. Save करा → 1-2 मिनिटांत live:
   `https://<तुमचं-username>.github.io/mi-aajpasun-daru-sodli/`
